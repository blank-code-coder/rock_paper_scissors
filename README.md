# rock_paper_scissors

This is a simple game of rock paper scissors played using a simple UI. The program was built entirely with HTML and Javascript. The user will be presented with three options for rock, paper or scissors. The game will go on until either the player or computer reaches 5 wins. Compared to the previous version I did, this uses DOM manipulation and uses a simple ui to get user input.

Live preview: https://blank-code-coder.github.io/rock_paper_scissors/
